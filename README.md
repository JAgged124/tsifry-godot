# Цифры — Godot 4.7, сборка APK

Версия **v2**, как веб-игра: меню, день/ночь, лавка, правила, баг-отчёт, поле 9 колонок.

## Скачать ZIP

https://github.com/JAgged124/tsifry-godot/archive/refs/heads/main.zip

Репозиторий: https://github.com/JAgged124/tsifry-godot

Распакуй архив. В корне будет `project.godot` — эту папку открывай в Godot.

## Сборка APK (Godot 4.7.2)

1. Открой папку проекта в Godot **4.7.2**.
2. **Редактор → Управление шаблонами экспорта** — шаблоны **4.7.2**.
3. JDK **17**, Android SDK API 34/35. Путь: **Настройки редактора → Export → Android**.
4. **Проект → Установить шаблон сборки Android** (нужен Gradle).
5. **Проект → Экспорт → Android → Экспортировать проект** → сохрани `Tsifry.apk` на диск.

Если кнопка экспорта серая — не сделан шаг 4.

Пакет: `com.tsifry.numbers`
